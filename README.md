# Job Application Form

A responsive job application form built with HTML and CSS as part of my web development learning journey.

## Features

- Full name and email fields
- Position selection dropdown
- Full-time and part-time availability options
- Motivation text area
- Form styling and validation states

## Technologies

- HTML5
- CSS3

## Learning Purpose

A hands-on project for practicing HTML forms, CSS selectors, pseudo-classes, and layout styling.
